# Excalifont

`Excalifont-Regular.woff2` is the hand-drawn typeface used by Excalidraw,
released under the **SIL Open Font License, Version 1.1**.

The OFL permits embedding the font in a document or application, including
commercial ones. It requires that the font itself is not sold on its own and
that this notice travels with the font file.

Full licence text: https://openfontlicense.org/

The subset here is the Latin subset shipped in the `@excalidraw/excalidraw`
npm package (v0.18.0), about 25 KB.
